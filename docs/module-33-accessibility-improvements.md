## Module 33 – Accessibility Improvements

### Objective

Improve usability for all users, including assistive-tech and large-text scenarios.

### Scope

- Semantic labels and hints for key controls.
- Dynamic text scaling checks (avoid clipping/overflow).
- Contrast and color reliance review.
- Keyboard focus order improvements where relevant.

### Key deliverables

- Accessibility audit checklist and fixes across core screens.
- VoiceOver/TalkBack pass for lock, list, details, import/export.
- Touch target size compliance.

### Integration notes

- Validate recent menu/sheet-heavy UI from Modules 11–19.

### Out of scope

- Full WCAG certification process.
