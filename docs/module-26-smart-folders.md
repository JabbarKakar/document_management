## Module 26 – Smart Folders

### Objective

Provide dynamic, saved views that auto-group documents by rules.

### Scope

- Built-in smart folders:
  - No category
  - No notes
  - Expiring soon
  - Recently added
- Optional user-defined rule sets later.

### Key deliverables

- Smart-folder rule evaluator service.
- Home UI entry point and list rendering integration.
- Counts on folder tiles/chips.

### Integration notes

- Reuse Module 11 filter predicates where possible.

### Out of scope

- Arbitrary custom query language.
