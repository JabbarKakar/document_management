## Module 25 – Tagging System

### Objective

Add flexible multi-tag organization beyond one category per document.

### Scope

- Create/edit/delete tags.
- Assign multiple tags per document.
- Filter documents by one or more tags.

### Key deliverables

- Isar model for tags + document-tag relation.
- Tag chips in details/edit flows.
- Tag management UI in Settings or Organization section.

### Integration notes

- Works alongside categories (do not replace categories).
- Module 11 filtering can be extended to include tags.

### Out of scope

- Nested tags / tag hierarchies.
