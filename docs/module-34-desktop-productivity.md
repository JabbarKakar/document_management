## Module 34 – Desktop Productivity Features

### Objective

Enhance desktop ergonomics for power users on Windows/macOS/Linux.

### Scope

- Drag-and-drop file import into vault.
- Keyboard shortcuts (new/import/search/lock).
- Right-click context menu on document rows.
- Improved split-pane style details/preview (optional phase 2).

### Key deliverables

- Desktop-only interaction handlers with platform guards.
- Shortcut map and discoverability hints.
- Consistent behavior with mobile actions.

### Integration notes

- Reuse Module 19 bulk import and Module 13 details actions.

### Out of scope

- Platform-specific native shell extensions.
