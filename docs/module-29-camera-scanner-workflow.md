## Module 29 – Camera Scanner Workflow

### Objective

Make capture-to-document faster with scan-oriented processing.

### Scope

- Guided camera scanner flow:
  - Auto edge detection/crop.
  - Perspective correction.
  - Simple enhancement presets (B/W, contrast, original).
- Save output as image or PDF.

### Key deliverables

- Scanner UI and processing pipeline.
- Multi-page scan session to single PDF export.
- Fast path into existing Add/Edit flows.

### Integration notes

- Reuse Module 17 replace-file path for replacing with scan output.

### Out of scope

- OCR text extraction (Module 15).
