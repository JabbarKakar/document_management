## Module 31 – Home Dashboard Widgets

### Objective

Add high-signal overview widgets to the vault home for quicker action.

### Scope

- Optional cards/widgets:
  - Expiring soon
  - Recently updated
  - Favorites
  - Uncategorized
- Tap-through into filtered views.

### Key deliverables

- Dashboard section component with compact cards.
- Data aggregation in provider/service layer.
- User preference to show/hide widgets.

### Integration notes

- Should compose cleanly with Module 26 smart folders.

### Out of scope

- External OS home-screen widgets.
